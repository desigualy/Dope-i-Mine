# Rive Import Protocol

1. Open Rive.
2. Create `Dope-i-Mine Avatar Library v1`.
3. Import SVGs from `assets/svg`.
4. Keep exact Component_* names.
5. Mark each imported artboard as a Rive Component.
6. Create Avatar_Main, Avatar_Library_QA, Avatar_Color_QA, Avatar_State_QA, Avatar_Preset_QA.
7. Bind colours using manifest/avatar_components.manifest.json.
8. Build Avatar_StateMachine.
9. Export .riv.
