# Avatar V4 Style Acceptance Checklist

## General

```text
[ ] Looks polished enough to sit beside Apple/Meta avatar references
[ ] Uses soft lighting/shading
[ ] Does not look like a flat SVG sticker
[ ] Does not look like the retired V2/V3 blob renderer
[ ] Face proportions feel human and friendly
[ ] Head, neck, and body align naturally
```

## Hair

```text
[ ] Hair sits on the scalp/head
[ ] Long hair uses rear/back layers
[ ] Hair never forms a beard-like mass
[ ] Hair does not cover the mouth/chin unless facial hair is selected
[ ] Afro/coily/ringlet hair has volume, depth, and believable shape
[ ] Braids/locs/twists do not look like a curtain wall
[ ] Short/shaved hair has visible hairline/scalp relationship
```

## Facial hair

```text
[ ] Moustache sits above upper lip only
[ ] Goatee sits around chin/lower lip
[ ] Short beard sits on lower cheeks/jaw/chin
[ ] Full beard does not start too high on the face
[ ] Facial hair is separate from hairstyle hair
```

## Skin details

```text
[ ] Freckles are subtle and organic
[ ] Vitiligo looks like natural pigmentation variation
[ ] Birthmarks support placement variation
[ ] Scars support placement variation
[ ] Mature lines are visible but not harsh
```

## Runtime contract

```text
[ ] Artboard is named Avatar
[ ] State machine is named AvatarState
[ ] skinTone input exists
[ ] faceShape input exists
[ ] hairPack input exists
[ ] hairStyle input exists
[ ] hairColor input exists
[ ] bodyPreset input exists
[ ] freckles input exists
[ ] vitiligo input exists
[ ] hasFacialHair input exists
[ ] hasGlasses input exists
```
