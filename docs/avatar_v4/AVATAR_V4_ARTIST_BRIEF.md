# Avatar Engine V4 — Artist Brief

## Product

Dope-i-Mine needs a premium avatar rig for a wellbeing/task support app. Users must feel represented, not mocked.

## Style reference

Target quality direction:

```text
Apple avatar headshot polish
Meta avatar full-body structure
soft 3D illustrated realism
warm, clean, friendly
not photorealistic
not childish blob art
not flat emoji art
```

## Emotional tone

The avatar should feel:

```text
safe
personal
modern
friendly
respectful
inclusive
calm
```

It must not feel:

```text
cheap
mocking
racially insensitive
overly comic
uncanny
generic
```

## First rig scope

The first `.riv` does not need every future option, but it must be built to expand.

Minimum visible support:

```text
8 skin tones
5 face shapes
6+ hair families
3+ body presets
freckles toggle
vitiligo toggle
glasses toggle
facial hair toggle
```

## Hair priority

Hair is the highest-priority visual area.

The old system failed because hair rendered like:

```text
a beard
a curtain
a side mass
a face-covering blob
```

The new rig must explicitly separate:

```text
hair_back
hair_front
facial_hair
face safe zone
chin/mouth clear zone
```

## Delivery

Deliver:

```text
base_avatar.riv
preview PNG 512x512
preview PNG 220x220
input documentation screenshot from Rive
layer/group screenshot from Rive
```
