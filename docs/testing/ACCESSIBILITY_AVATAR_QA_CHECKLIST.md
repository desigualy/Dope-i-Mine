# Accessibility and Avatar QA Checklist

| Check | Expected result | Pass/Fail | Notes |
| --- | --- | --- | --- |
| Large text mode | Layout remains usable with no clipped primary controls. |  |  |
| Reduced motion | Non-essential motion is disabled. |  |  |
| Sensory-friendly colours | Colours apply and remain readable. |  |  |
| High contrast | Text and controls remain readable. |  |  |
| Calm mode | Visual noise is reduced. |  |  |
| Screen reader primary controls | Primary controls have meaningful labels. |  |  |
| Voice-first mode | Voice controls are exposed where expected. |  |  |
| Body-double leave/report controls | Leave and report remain visible. |  |  |
| Caregiver remove/revoke controls | Remove/revoke controls remain clear. |  |  |
| Avatar V4 screen opens | Avatar customizer/onboarding opens without red screen. |  |  |
| Selected avatar persists after restart | Selected avatar remains selected. |  |  |
| Private abstract mode | Private/abstract avatar renders without personal image. |  |  |
| generatedImageUrl exists | Generated image is shown. |  |  |
| Generated image absent/fails/offline/private | Fallback appears only in these states. |  |  |
| Dope-i mascot separation | Mascot is separate from user avatar renderer. |  |  |
| Avatar V3 files/routes | Avatar V3 is not restored or routed. |  |  |
