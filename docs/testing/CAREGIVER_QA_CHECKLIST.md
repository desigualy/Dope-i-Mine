# Caregiver QA Checklist

| Check | Expected result | Pass/Fail | Notes |
| --- | --- | --- | --- |
| Supported user adds caregiver | Pending caregiver appears with respectful support copy. |  |  |
| Supported user removes pending caregiver | Pending invite disappears and cannot be accepted later. |  |  |
| Caregiver confirms invite | Relationship becomes accepted. |  |  |
| Caregiver signs in with assigned/set password flow | Temporary-password gate and force-password-change flow remain intact. |  |  |
| Caregiver assigns task | Supported user receives assigned support task. |  |  |
| Supported user completes assignment | Completion is saved for supported user. |  |  |
| Caregiver views permitted progress | Only permitted progress is visible. |  |  |
| Supported user removes caregiver | Relationship is revoked. |  |  |
| Removed caregiver signs in | Removed caregiver loses access to that supported user. |  |  |
| Caregiver sends gentle nudge | Supported user receives supportive nudge if enabled. |  |  |
| Supported user reviews permissions | Permission language explains revoke/remove clearly. |  |  |
